# inmc-invkeeper

사망 시 인벤토리·경험치를 **월드·권한·보호 아이템 기준으로 관리**하고, 무덤과 영혼각인을 제공합니다.

1세대 `InvKeeper`(Java/Maven)를 5세대 기준으로 새로 만든 것입니다. 원본 폴더 `inv/` 는 건드리지
않았고, 각인 PDC 키만 1세대와 호환됩니다 — 서버에 이미 돌아다니는 각인 아이템이 그대로 인식됩니다.

## 요구사항

| | |
|---|---|
| 서버 | Paper 26.2 이상 |
| Java | 25 |
| **필수 의존성** | **`inmc-core`** — 없으면 플러그인이 켜지지 않습니다 |
| 선택 연동 | MMOItems · MythicLib · ItemsAdder / Nexo / Oraxen (전부 리플렉션, 없어도 동작) |

`inmc-core` 가 kotlin-stdlib 과 공용 프레임워크를 들고 있습니다. `plugins/` 에 같이 넣어주세요.

## 하는 일

**드랍 규칙** — 죽을 때 얼마를 잃는지를 월드별·권한별로 정합니다. 권한이 월드보다 강합니다
(등급이 높으면 어느 월드에서 죽든 그 등급의 드랍량을 따릅니다). 아이템은 **칸 단위**로,
무작위로 고른 칸을 통째로 잃습니다.

**무덤** — 잃은 몫이 바닥에 흩어지는 대신 사망 지점의 무덤에 담깁니다. 주인은 우클릭으로 언제든
회수하고, 다른 사람은 도굴 도구로 시전해야 엽니다. 도굴 중에 주인이 확인하면 취소됩니다.
사라진 무덤은 사망 시점 원본과 함께 기록에 남아, 관리자가 나중에 돌려줄 수 있습니다.

**영혼각인** — 아이템을 한 사람에게 묶습니다. 남이 줍지도, 쓰지도, 옮기지도 못하고, 죽어도
떨어지지 않습니다. 시간으로 만료되거나 사망 횟수로 소모되는 두 방식이 있습니다.

**보호권** — 소모형(죽는 순간 한 장 소모, 완전 보호)과 시간형(우클릭, 일정 시간 보호).

## 아이템 등록

보호권·각인기·도굴 도구·자동각인 대상은 전부 **손에 든 아이템을 그대로 등록**합니다.

```
/인벤키퍼 관리
```

목록 화면 45번 버튼에 손에 든 아이템을 등록하고, 이어지는 설정 화면에서 종류와 각인을 정합니다.
MMOItems·ItemsAdder·바닐라·직접 만든 아이템이 전부 같은 길로 들어옵니다.

`items.yml` 을 직접 고쳐도 됩니다. `/인벤키퍼 리로드` 가 다시 읽습니다.

### 자동각인

등록한 아이템을 **처음 손에 넣은 사람**에게 각인이 자동으로 찍힙니다. 보스 드랍이나 시즌 한정
아이템을 판 사람 손에 묶어둘 때 씁니다.

- 아이템마다 **시간(분)** 또는 **사망 횟수** 중 하나로 값을 따로 줍니다
- 등록 방식이 동적(참조)이든 스냅샷(고정)이든 똑같이 동작합니다
- 줍기·인벤토리 이동은 그 자리에서, `/give` 처럼 이벤트가 없는 경로는 만료 스캐너가 덮습니다

"처음"의 판정은 따로 기록하지 않습니다 — **각인 주인이 없으면 처음**입니다. 각인이 만료돼
주인이 지워지면 다음에 줍는 사람이 새 주인이 됩니다.

### 자체 각인

자동각인과 다릅니다. **지급받는 그 사람**에게 바로 묶입니다 — 보호권이나 각인기를 팔거나
넘기지 못하게 할 때 씁니다.

## 명령어

전부 `/인벤키퍼` (별칭 `/invkeeper`, `/ik`) 아래에 있습니다.

| | |
|---|---|
| `상태` | 지금 월드에서 얼마를 잃는지 / 보호 남은 시간 |
| `관리` | 아이템 등록·설정 GUI |
| `등록 <종류> <이름>` · `등록해제 <이름>` · `목록` | 명령어로 같은 일 |
| `지급 <대상> <개수> <이름>` | 등록 아이템 지급 |
| `각인 확인` · `각인 해제` | 손에 든 아이템의 각인 |
| `무덤 목록` | 살아 있는 무덤 화면 — **클릭하면 그 자리로 텔레포트** (콘솔은 채팅 목록) |
| `무덤 기록 <대상>` | 그 사람의 살아 있는 무덤 + 사라진 무덤 기록. 좌클릭 텔레포트, 우클릭 남은 아이템 회수 (오프라인 가능) |
| `무덤 리로드` | 설정을 다시 읽고 무덤 홀로그램을 다시 띄웁니다 |
| `리로드` | `config.yml` · `messages.yml` · `items.yml` 다시 읽기 |

## 권한

| | 기본 |
|---|---|
| `invkeeper.status` | true — `상태` 명령 |
| `invkeeper.admin` | op — 관리 명령어 전부 |
| `invkeeper.grave.admin` | op — 무덤 명령만 (운영진에게 무덤만 맡길 때) |
| `invkeeper.soulbind.bypass` | false — 남의 각인 아이템을 만질 수 있음 |
| `invkeeper.grave.bypass` | op — 도굴 도구 없이 남의 무덤 열기 |
| `invkeeper.grave.time.vip` / `.vvip` | false — 무덤 만료 시간 덮어쓰기 |
| `invkeeper.drop.1` ~ `.11` | false — 드랍량 등급 |

## 설정 파일

| | |
|---|---|
| `config.yml` | 드랍 규칙 · 무덤 · 각인 스캔 주기 |
| `items.yml` | 등록된 아이템 (GUI 가 여기에 씁니다) |
| `messages.yml` | 모든 문구. MiniMessage 표기, 예전 색코드도 읽힙니다 |

## 빌드

```bash
cd .. && ./gradlew :invkeeper:build
```

`inmc-invkeeper/build/libs/inmc-invkeeper-1.0.0.jar` 이 나옵니다.
